/*---------- How to use JobCraft ----------*/

1) Open index.html and fill in all the required fields in the form.
2) Review the details on the results page to ensure accuracy.
3) If there is something which you want to changes, go back to the form (Back button does not erase the previously uploaded files, reloading the page will erase the previously uploaded files) and edit the job description and run the tool again. This process can be repeated as long as the page is not reloaded.
4) Verify the downloaded files and make any necessary edits. The editing in the word document can be avoided by editing the text in the job description. This step avoids the formatting errors in word that can accidentally creep in.
5) Apply for the desired job using the generated documents.

/*-------- How does JobCraft work? --------*/
/*---------- Code logic explained ---------*/

JobCraft is designed to streamline the tedious task of copy-pasting basic details into your cover letter and CV while applying for jobs.

1) JobCraft takes the job description, CV template, cover letter template, and additional documents as inputs. All the files and the job description are required.
	- CV and cover letter templates are Word documents where keywords are enclosed in curly braces (e.g., {job_title}, {date}, etc.).
	
2) When the 'Process Job Application' button is clicked, the tool extracts your name from the cover letter (typically the name after the closing, such as "Regards") and suggests possible names for you to choose.
	- The selected name is used to name the final document (e.g., Anschreiben_Srikanth.docx if you choose "Srikanth"). This feature helps in saving files professionally.

3) The files are then zipped, and a download box appears, allowing you to download the zip file.

4) A dialog box appears, offering a suggested folder name for saving the documents. 
	- This step is optional, but useful for those who apply for different job types and prefer organizing their files into folders. If the tool finds words like 'crash' or 'Fahrzeugsicherheit,' it suggests naming the folder Crash; otherwise, Non-Crash is suggested. Additionally, it recommends a folder name in the format CompanyName_Date.

5) A results page appears, allowing you to review all the details. It's highly recommended to carefully check this page and compare it with the job description to ensure the correct information appears in the final documents.

6) The company name is extracted from the job description.
	- The tool looks for terms like 'GmbH' or 'AG' to recognize company names.

7) The company's address is identified from the job description if it includes a street name and number, followed by a zip code and city. The country is optional.

8) The job title and reference number are also extracted from the job description.
	- The tool recognizes job titles by looking for combinations like m/w/d, w/f/x, or other variations of m/f/x/d/w. It looks for keywords like 'Referenznummer' or 'Job ID' to identify the reference number.

9) For the contact person, the tool searches for keywords such as Herr, Frau, Dr., Mr., Ms., or Mrs. in the job description.

10) The tool checks the newly generated cover letter and CV for the word "undefined." 
	- If found, "undefined" is highlighted in bold red so that the user can easily spot it and make necessary corrections. At this stage, you can either edit the downloaded files manually or use the 'back' button in the tool to make corrections based on the job description. The usage of back button is recommended at this step.

11) The ATS check provides an estimated ATS score, suggestions for improvement, a modified cover letter, and a list of relevant keywords. If the job description is not in English, the tool also offers a translation of the keywords and cover letter. 
	- The tool generates a prompt with the job description, CV, and cover letter, which can be used with ChatGPT. However, integration with ChatGPT is not yet supported, so the user must manually copy the prompt, log into ChatGPT, and paste it to get feedback. Any suggestions from ChatGPT must also be manually implemented in the documents.

JobCraft aims to significantly reduce the time spent on editing during the job application process.

Note: The code can be modified at the user's own risk if they have knowledge of HTML, CSS, and JavaScript.

/*------------ Additional Notes -----------*/

1) Internet Connectivity: The app requires an active internet connection, as index.html links to external libraries through <script src="..."></script>. To use the app offline, download these libraries as separate .js files and link them locally in index.html.

2) Library URLs: Ensure that the URLs in <script src="..."></script> tags in index.html are functional. To check, paste the URL in a browser: 
	- If you see the code displayed as plain text, the link is working.
	- If a 404 error appears, you need to find an updated link to the correct library.

3) Custom Variables: The CV and cover letter templates should include placeholders in the following format:
Example: {first_name}, {last_name}, {company_name}, {new_Company_First_Word}. These variables are defined in the generate function in script.js.
You can add new placeholders, but additional code may be required to implement them.
